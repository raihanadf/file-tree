## 1.0.0

- first release. a literal file tree for macos: open a folder and it grows out as a mossy pixel-art branch, files hang off twigs, close it and the branch pulls back in, deepest first.
- opens in your home folder every launch, the folder button switches for the session.
- keyboard (hjkl or arrows, return, space) and mouse (click folders, double-click files, drag or scroll to pan).
- settings for pixel size, branch size, moss, font size, grow speed, hidden files and light or dark background.
- smooth at 60fps on big folders: about 2 ms a frame with a 200-item downloads folder open.
